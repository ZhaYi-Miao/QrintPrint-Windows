# QrintPrint Web 打印前端

错题小印（QrintPrint）打印机的浏览器控制面板。直接在浏览器中远程打印文本、图片、Markdown、条码、Word/PDF、表格和课程表，并支持实时打印效果预览。

## 功能特性

- **实时预览**：输入内容后自动显示打印效果（服务端渲染二值化图像回传）
- **文本打印**：字号、加粗/斜体/下划线、字间距、行间距、边距、公式模式（LaTeX）
- **图片打印**：拖拽/选择图片，支持抖动算法（Floyd-Steinberg / Burkes / 无）与 0-255 二值化阈值
- **Markdown 打印**：标题、加粗、斜体、列表、引用、代码块
- **条码打印**：一维码（EAN-13、Code128 等）与二维码（QR、DataMatrix、PDF-417、Aztec）
- **Word / PDF 打印**：上传 `.docx` / `.pdf` 文件，图片显示占位、表格转 ASCII 网格
- **表格打印**：1-8 列、1-20 行，支持自定义列宽权重
- **课程表打印**：7 天、每天最多 12 节，点击单元格直接编辑

## 使用前提

1. 桌面程序 **QrintPrint v1.1.0 及以上** 已在本机运行
2. 桌面程序"设置 → 远程打印"已开启 HTTP 服务，并记住端口（默认 `8512`）
3. 拥有至少一个 API Key（Token）

> 浏览器与程序可不在同一台电脑，只要网络互通即可。HTML 为纯前端单文件，**无需部署服务器**，双击用浏览器打开即可。

## 使用步骤

1. 用浏览器打开 `index.html`（支持双击直开，也可放任意静态服务器）
2. 填写 **服务地址**，例如 `http://127.0.0.1:8512`
3. 填写 **API Token**（桌面程序"设置 → 远程打印"中查看/新建 Key）
4. 点击 **测试连接**，提示"已连接"后即可使用
5. 选择功能标签页，填写内容，点击对应 **打印** 按钮

> 连接配置保存在浏览器本地（localStorage），下次打开自动恢复。

## 实时预览说明

- 内容为空或未填写连接信息时，预览区显示提示而非请求
- 快速输入自动防抖（300ms），内容变化才请求服务端渲染
- 预览失败会显示具体原因（如内容格式不合法、服务端未连接）

## 表格列宽权重

表格 tab 的"列宽权重"输入框可用逗号分隔多个正数，指定各列宽度比例：

```
表头：科目,成绩
数据：语文,92
列宽权重：20,30
```

表示第一列占 20 份、第二列占 30 份。留空时按内容自动分配。

## 浏览器兼容

- Chrome / Edge / Firefox 现代版本
- 需支持 `fetch`、`FileReader`、`localStorage`（现代浏览器均支持）
- 跨域：程序服务端已开启 CORS，允许 `file://` 与任意来源访问
